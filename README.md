# ⏰ TagTime

This is a modern Android alarm clock application built using **Jetpack Compose** and adhering to the **Material 3** design system. The app allows users to set an alarm time, toggle its status (ON/OFF), and link it to physical identifiers via both NFC tags and QR codes for easy activation/deactivation.

## ✨ Key Features

*   **Time Setting**: Easily view and click to adjust the current alarm time.
*   **Alarm Toggle**: Simple ON/OFF switch to control the alarm state.
*   **NFC Tag Linking**: Link a physical NFC tag directly to the alarm, allowing for quick activation or deactivation by tapping it on the device.
*   **QR Code Linking**: Scan a QR code (either generated by the app or from an external source) to link it to the alarm.
*   **Alarm Ringing Screen**: A dedicated full-screen UI that appears when the alarm triggers, featuring clear instructions and a prominent button/area for deactivation.
*   **Foreground Service & Watchdog**: The alarm runs as a Foreground Service, ensuring it stays active even when the app is backgrounded. A "Watchdog" mechanism aggressively brings the ringing screen to the front every second to prevent dismissal issues.

## 🛠️ Technical Stack

*   **Language**: Kotlin
*   **UI Toolkit**: Jetpack Compose
*   **Design System**: Material 3 (M3)
*   **Core Components**: `AlarmService` (Foreground Service), `NfcAdapter`, `GmsBarcodeScanning` (for QR).

## 🚀 Getting Started

Follow these steps to run the application in Android Studio:

1.  **Clone/Open Project**: Open the `AlarmClock` project in Android Studio.
2.  **Sync Gradle**: Ensure your dependencies are synced (`File -> Sync Project with Gradle Files`).
3.  **Run**: Select an emulator or physical device and click the Run button (▶️).

### ⚙️ Usage Flow

1.  **Initial View**: The main screen displays the current time, alarm status (ON/OFF), and linking options.
2.  **Linking**: Tap "Link Tag" or "Link QR" to initiate scanning/pairing.
3.  **Alarm Triggered**: When the set time arrives, the `AlarmService` starts ringing and brings up the dedicated Alarm Ringing Screen.
4.  **Deactivation**: On the ringing screen, you can either:
    *   Tap the **Scan QR Code** button to open the camera.
    *   Tap your linked NFC tag (if available).

## 💡 Future Enhancements (Roadmap)

Based on current features and best practices, here are some ideas for future development:

*   **Alarm Scheduling**: Allow setting multiple alarms or scheduling alarms for specific days of the week.
*   **Sound Customization**: Implement a selection screen to choose different ringtones instead of relying solely on the default system alarm sound.
*   **Vibration Pattern**: Add customizable vibration patterns alongside the ringing sound.
*   **Persistence/State Management**: While basic state is saved, implementing a more robust ViewModel/Repository pattern would allow for better handling of complex states (e.g., "Alarm set to 7:30 AM on Mon/Wed/Fri").
